# 人工校准流程 v1.0（Judge 上线前置条件）

状态：设计定稿、未启动。真实 LLM 态配置并完成首轮 Judge 运行后执行。

## 1. 校准轮（首轮）

| 项 | 规则 |
|---|---|
| 覆盖范围 | **P0 级 L4 案例全量人评**（L4-016/017/018/019、L3-013 Judge 断言、HO-035）+ 其余 L4 案例 30% 分层随机抽样 |
| 评审人 | ≥2 人独立双盲（不看到 Judge 结论、互相不见对方判定） |
| 评审材料 | 与 Judge 完全相同的证据包 + rubric_l4_v0.2（同一版本号） |
| 分歧处理 | 分歧案例提交 PM 终裁，裁定结果回写为锚点例（进入下一版 rubric 附录） |

## 2. 稳定门槛

- 单维度人机一致率 ≥ **90%**，或 Cohen's κ ≥ **0.6**；
- 达标后降级为常规轮：30% 分层随机双盲抽检；
- 未达标：修订 rubric 临界例 / 证据包结构后重跑校准轮（Judge 侧调参禁止使用 holdout）。

## 4. 记录与版本纪律

- 每轮校准记录：评审人、案例集版本与哈希、rubric/prompt 版本、Judge 配置、
  逐案例判定对照表、一致率/κ 计算过程；
- 校准数据集只增不改；分歧锚点例进入 rubric 附录时递增 rubric 版本号；
- 校准结果不用于调 holdout 案例。

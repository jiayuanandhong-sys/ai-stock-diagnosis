# 试用部署与运维说明（T-09，ADR-004：本地运行 + 轻量域名）

## 一、启动与验证

1. **启动**：双击 `deploy/start_server.bat`（或命令行运行它）。
   - 默认端口 `8000`；`SDD_POOL_MODE=demo`（20 只演示池，秒级可用）。
   - 改为完整四池模式：编辑 bat 中 `SDD_POOL_MODE=full`（首次运行需预热缓存，见下）。
2. **本机自检**：浏览器打开 `http://127.0.0.1:8000`，输入 `603799` 应能出完整报告。
3. **局域网试用**：朋友与你在同一 Wi-Fi 时，可直接访问 `http://<你的内网IP>:8000`
   （内网 IP 用 `ipconfig` 查看，如 `http://192.168.x.x:8000`）。

## 二、轻量域名（外网试用入口，二选一）

| 方案 | 步骤 | 说明 |
|---|---|---|
| **花生壳（内网穿透）** | ① oray.com 注册（免费版有流量额度，超出需实名+付费档）② 下载 Windows 客户端并登录 ③ 添加"内网穿透"映射：内网主机 `127.0.0.1`，内网端口 `8000`，协议 HTTP ④ 客户端生成一个外网域名，朋友手机浏览器直接访问 | 国内访问稳定；免费额度够 5–10 人轻量试用；需要你本人注册账号（涉及实名，AI 不代办） |
| **ngrok** | ① ngrok.com 注册（免费）② 下载 ngrok.exe ③ 运行 `ngrok http 8000` ④ 控制台给出的 `https://xxxx.ngrok-free.app` 即外网入口 | 零实名；但免费版域名每次重启会变、国内直连速度不稳定 |

> 注册动作涉及账号/实名/可能的付费档位，按《自主连续开发规则》暂停项处理：**由 PM 本人操作**，
> 完成后把域名告知 AI 或直接告知试用用户即可。

## 三、重启与恢复（目标：10 分钟内恢复）

| 故障 | 恢复动作 | 耗时 |
|---|---|---|
| 服务意外退出 | 重新双击 `start_server.bat` | <1 分钟 |
| 电脑重启 | 同上（无状态服务，重启即恢复；限流计数为内存态，重启清零属预期行为） | <1 分钟 |
| 数据缓存损坏/缺失 | 删除 `data_cache/` 下对应 parquet 后重跑诊断，自动重拉（20 只演示池约 40–90 秒） | <2 分钟 |
| 交易日历缺失 | 自动联网重建（`data_cache/trade_calendar.json`） | <10 秒 |
| 网络中断 | 恢复网络后无需任何操作（缓存当日数据仍可用，仅新数据无法更新） | — |

## 四、进程守护（试用可用性）

MVP 试用规模（5–10 人）采用**人工重启**策略（ADR-003⑤ 单人+AI 量级）：
- 服务窗口期保持电脑不休眠（电源计划设为"从不睡眠"）；
- 若需无人值守，可后续用 NSSM 将 `start_server.bat` 注册为 Windows 服务（**属新工具引入，如需要走 CR**）。

## 五、试用前检查单（PM 每次开服前过一遍）

- [ ] `http://127.0.0.1:8000` 本机可开
- [ ] 输入 `603799` 能出完整报告（17 章节）
- [ ] 输入 `12345` 出"格式无效"提示（错误路径正常）
- [ ] 外网域名（如已配置）手机可访问
- [ ] 限流上限合适（默认 50 次/日/IP，bat 里可调 `SDD_DAILY_LIMIT`）

## 1. 背景

- 产品背景：面向股票持仓用户，解决"该走该留"的决策焦虑（2026-10-17 确认）。

## 2. 目标与度量 ✅
- 学习目标：完整走通 SDD 五阶段，理解 PM 如何以规格驱动开发。
- 产品目标：降低持仓决策的不确定性。
- 成功度量：5–10 名真实持仓用户试用；成功 = 试用期结束后 ≥20% 用户愿意付费购买服务。
  - 执行提示：真实用户需用户提前物色；Plan 阶段排为早期任务。功能 AC（第 8 节）与试用度量为 Verify 阶段两条独立验收线。

## 3. 目标用户与核心场景 ✅
- 目标用户：持有个股、对该股去留拿不定主意的个人投资者。
- 市场范围：仅 A 股；可服务范围 = 中证四大宽基同池成分股。
- 核心场景 SCN-001：用户持有某只 A 股个股，对"留、补/减/换"产生决策焦虑，输入股票代码，获得该股合并版因子诊断报告（简要+详细），作为决策参考物。
- 错误路径场景：
  - SCN-002：输入无效/格式错误的代码 → 明确错误提示，不生成报告。
  - SCN-003：输入四池之外的 A 股（非成分微盘股、北交所等）→ 拒绝并提示支持范围。
- 场景约束：报告为通用客观体检，不含个人处境章节；间接支撑决策；零个人数据收集。

## 4. MVP 范围 / 非目标 ✅
- 范围（一句话）：用户输入一个 A 股股票代码 → 输出该股的周频量化因子诊断报告（合并版：简要+详细，含分数与分数解读）。
- 非目标（范围冻结）：
  - NG-001：不做盘中实时诊断，仅使用收盘后数据；
  - NG-002：不做多股/组合诊断与持仓优化建议；
  - NG-003：不做定期重诊、异动推送、提醒类功能；
  - NG-004：不做自动交易、代客下单、券商账户对接；
  - NG-005：不做社区、观点讨论、UGC；
  - NG-006（CR-S-002，2026-10-17）：不使用分钟线/逐笔成交数据，MVP 全部因子仅基于日线级行情与估值数据计算。

## 5. 需求（REQ，定稿 ✅）
- REQ-001：用户在网页上输入一个 A 股股票代码（四池成分股），发起对应该股的一次周频因子诊断，**在线获得**合并版诊断报告（简要+详细），并支持下载（CR-S-001，2026-10-17）。
  - 输入契约：仅股票代码（1 个字段）；网页无登录、无其他信息采集（BR-004）。
  - 同池口径：按归属成分股指数定池，四池：沪深 300 / 中证 500 / 中证 1000 / 中证 2000（BR-008）。
- REQ-002：诊断报告结构以样例报告（INPUT-001）为权威参照。合并版 = 简要报告 + 详细报告：
  - 简要报告：元信息（代码/观察日/同池/出分日）+ 汇总表 → 第一层·一句话结论 → 四个观察侧面 → 股性曲线与 H → "怎么读这个分数" → 第二层·白话解释（①用的数据 ②用的分析工具 ③合成一个数 ④是什么意思/不是什么意思 ⑤什么时候会变）→ 风险与边界；
  - 详细报告：因子视角的客观评估 → 当前状态的两种比较（S vs H）→ 分项信号的分布 → 宽口径维度观察（各维度因子数量：3/7/4/4，共 18 项，见附表 A）→ 自身历史位置与持续性（含轨迹图）→ 当前得分在过去出现的位置 → 统计证据与解释边界（同池历史关联、因子相关性）→ 匿名因子明细（18 项分 3 表：第 1–6 / 7–12 / 13–18 项）→ 数学方法与数据覆盖。
- REQ-003：诊断结果包含建议复核日（生成后 5 个交易日内），报告内打印该日期；周涨跌幅绝对值≥5%、业绩预告/财报、成交结构异常时提示提前复核。报告仅打印日期，不做自动提醒（受 NG-003 约束）。

## 7. 业务规则（BR，定稿 ✅）
- BR-001：Spec 阶段所有业务行为决策由 PM（用户）确认；未确认内容不得进入 REQ/AC。
- BR-002：诊断输出不得超出已确认的合规边界（分数+解读，不输出直接操作建议）。
- BR-003：分数仅代表个股相对强弱打分，不代表概率、可能性或涨跌预期；分数解读仅解释分数构成与多空因素，不出现"买/卖/加仓/减仓/清仓"等操作动词，并附免责声明；样例报告解释边界文案作为合规基线沿用。
- BR-004：MVP 不收集任何用户个人持仓数据；用户输入仅股票代码。
- BR-005（范围冻结）：除"代码输入 → 个股量化因子诊断报告输出"外，任何新功能进入 MVP 必须走 CR 并由 PM 重新审批。
- BR-006（分数体系；输入口径经 CR-S-002 变更）：因子分 = 统一方向后的平均并列名次在同池的百分位分数（0–100）；综合分 S = 有效因子等权平均后再放回同池重新排名；H = 历史位置参考分（此前 52 个完成周相对位置）；四个观察侧面仅用于拆解，不另设权重；缺失项不填分、不计权。**MVP 输入口径：仅日线级行情与估值数据（CR-S-002，2026-10-17，见 NG-006）**。**因子集合：18 项日线级因子，四侧面（估值 3 / 价格 7 / 交易 4 / 风险 4），详见附表 A（2026-10-17 PM 审定冻结；增删改任何因子必须走 CR）。**
- BR-007（分档口径）：高于 60 红色（偏有利）、低于 40 绿色（偏不利）、40–60 中性（深灰）；分组采用十分组。（历史口径"五分位、50 分界"作废，2026-10-17 裁决）
- BR-008（同池规则）：S 按股票归属的成分股指数在四池之一内计算与排名——沪深 300 / 中证 500 / 中证 1000 / 中证 2000；报告元信息须注明所用同池。**Plan 阶段第一优先验证项：中证 1000/2000 池的分钟线/逐笔数据获取与算力成本；若不可行，本条走 CR 回炉。**
- BR-009（池外处理，Gate S 确认）：四池之外的 A 股（非成分微盘股、北交所个股、新股等）拒绝服务并提示当前支持范围。

## 8. 验收条件（AC，定稿 ✅）
> 追踪：REQ-001 ← AC-001~010；Verify 阶段每条 AC 映射测试用例（TC）。
- AC-001（主路径·报告完整性）：输入任一四池成分股代码，生成合并版报告；简要与详细两大部分的章节与 REQ-002 清单一一对应，无缺章。
- AC-002（分数口径）：S 与 H 按 BR-006 规则计算；四侧面得分仅为拆解展示，不参与加权。
- AC-003（分池正确性）：分别输入沪深 300、中证 500、中证 1000、中证 2000 成分股各 1 只，报告元信息的"同池"标注与所属池一致，分数在对应池内排名。
- AC-004（分档着色）：报告中所有分数着色满足 >60 红、<40 绿、40–60 中性；分组为十分组。
- AC-005（合规文案）：报告全文不出现"买/卖/加仓/减仓/清仓"等操作动词（可测：关键词扫描）；包含免责声明与"分数不代表概率/涨跌预期"的口径说明。
- AC-006（复核日）：报告打印建议复核日 = 出分日 + 5 个交易日。
- AC-007（错误路径·无效代码）：输入不存在或格式错误的代码，返回明确错误提示，不生成报告。
- AC-008（错误路径·池外股票）：输入四池之外 A 股代码，返回"暂不支持 + 支持范围说明"，不生成报告。
- AC-009（数据零收集）：网页发起诊断的请求载荷除股票代码外不携带任何其他字段；页面无登录、无用户信息采集（可测：请求载荷检查 + 页面元素审查；CR-S-001 改写）。
- AC-010（解释边界文案基线）：报告包含样例报告的关键边界语句（"怎么读这个分数""风险与边界"章节在位）。
- AC-011（在线查看与下载，←CR-S-001）：输入合法代码后，网页可在线完整查看合并版报告，并可下载文件版报告（下载成功且可打开、内容与在线版一致）。

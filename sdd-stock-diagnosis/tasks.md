## 2. 任务明细（每任务含 DoD 验收条件）

### T-01 合规检查器（独立工具）
- 目标：AC-005 的机械化执行器，供 T-05/T-06 强制调用。
- 产出：`src/compliance.py`（绝对禁词表 ≥11 词 + 边界文案存在性检查 + 免责声明存在性）+ 用例集。
- DoD：
  1. 正例/反例用例全通过（含 Spike-2 实战案例：免责声明含"买入/卖出"必须判 FAIL）；
  2. 提供 `scan(text) -> (pass, hits)` 纯函数接口，可单测、可在生成链路内联调用；
  3. 禁词表数据外置（JSON），增删禁词不改代码。

### T-02 数据层：多源拉取与缓存
- 目标：稳定获取全四池日线行情 + 估值（52 周深度）。
- 产出：`src/data_fetcher.py`：新浪主源/东财备援自动切换 + 百度估值 + parquet 本地缓存 + 失败重试。
- DoD：
  1. 样本集 20 只（含中证 2000 小盘股、含 603799）拉取 20/20 成功；
  2. 人为封禁主源（模拟断连）自动切换备援，全程不崩溃；
  3. 二次运行命中缓存（0 外网请求，用请求计数验证）；
  4. 相同输入下因子原始值与 Spike-2 结果一致（复算比对）。

### T-03 池管理
- 目标：四池名单可信 + 归属判定 + 池外拒绝。
- 产出：`src/pool_manager.py`：中证官网名单拉取 + 带日期戳本地快照 + `resolve_pool(code)` 判定。
- DoD：
  1. 四池名单各拉取成功并落快照（JSON），可从快照离线恢复；
  2. 603799 → 沪深 300；每池抽 1 只成分股归属正确（AC-003 用例）；
  3. 北交所代码/非成分微盘股 → 返回"暂不支持 + 支持范围"结构化结果（不生成报告），与 BR-009 文案一致。

### T-04 因子引擎
- 目标：附表 A 18 项因子 → 同池百分位 → S（两级排名）→ H（正式口径：18 因子周频 S 的 52 完成周历史位置）。
- 产出：`src/factor_engine.py` + 口径单测。
- DoD：
  1. 单测覆盖：并列名次取平均、方向统一（低=有利因子反转）、缺失不填分不计权（BR-006）；
  2. S 合成后放回同池重新排名（两级排名），抽测 2 只股票手算比对；
  3. H 正式口径实跑：52 完成周窗口逐周回算，与 Spike-2 简化口径的结果差异留书面说明（为何不同、正式口径更准在哪）；
  4. 全部分数着色分档符合 BR-007（>60 红 / <40 绿 / 40–60 深灰）。

### T-05 报告生成器（合并版）
- 目标：REQ-002 章节清单一一落地的合并版报告（简要+详细）。
- 产出：`src/report_builder.py`：HTML 模板（简要/详细同构）+ python-docx 组装 + matplotlib 图表 4 张 + 复核日计算（交易日历 +5 交易日）。
- DoD：
  1. 章节完整性清单核对：简要+详细全部章节与 REQ-002 一一对应，无缺章（AC-001）；
  2. 分档着色、分组口径与 BR-007 一致（AC-004）；
  3. 复核日 = 出分日 + 5 个交易日（AC-006），跨节假日用例通过；
  4. "怎么读这个分数""风险与边界"章节在位且含口径语句（AC-010）；
  5. 组装最后一步强制调用 T-01 扫描，FAIL 即阻断输出。

### T-06 解读生成接口（可插拔，ADR-003④）
- 目标：统一接口下 LLM 实现为主、模板实现兜底；LLM 文本未经扫描禁止展示。
- 产出：`src/interpretation/`（`base.py` 接口 + `llm_impl.py` + `template_impl.py` + 工厂函数按环境变量切换）。
- DoD：
  1. 接口定义冻结：输入=分数+因子结构化数据（S/H/四侧面/18 因子分/同池元信息），输出=解读文本 + 生成器标识；
  2. LLM 实现经环境变量配置密钥，未配置自动降级模板实现，服务不中断；
  3. **硬门禁链路测试**：LLM 返回含禁词文本（注入式用例）→ 扫描 FAIL → 重试 1 次 → 仍 FAIL → 自动回退模板实现，最终展示文本必 PASS（AC-005）；
  4. 模板实现的输出与 Spike-2 演示报告文风一致（基线保障）。

### T-07 Web 应用（FastAPI）
- 目标：CR-S-001 定义的网页自助载体端到端。
- 产出：`src/app.py` + 静态输入页 + 报告在线页 + docx 下载端点 + 调用链（T-02→T-03→T-04→T-05/T-06）。
- DoD：
  1. 主路径：输入 603799 → 在线完整查看合并版报告 → docx 下载可打开且内容一致（AC-011）；
  2. 请求载荷除代码外零字段、无登录无 Cookie 采集（AC-009，抓包核对）；
  3. 报告页为服务端渲染（无前端框架），加载无 JS 依赖也能看核心内容。

### T-08 错误路径与限流
- 目标：SCN-002/003 两条错误路径 + 防滥用。
- 产出：错误处理中间件 + 限流器（单 IP 每日次数上限，内存计数即可）。
- DoD：
  1. 无效/格式错误代码 → 明确错误提示，不生成报告（AC-007）；
  2. 池外 A 股 → "暂不支持 + 支持范围"提示文案（AC-008，与 T-03 判定一致）；
  3. 超限请求返回限流提示，服务不崩（简单并发用例）。

### T-09 本地部署 + 轻量域名（ADR-004）
- 目标：朋友在外网可用的试用入口。
- 产出：启动脚本 + 内网穿透/轻量域名配置 + 一页运维说明（重启/断网恢复/缓存重建）。
- DoD：
  1. 外网（手机浏览器）经域名完成一次完整诊断（真实截图证据）；
  2. 本机重启后按说明 10 分钟内恢复服务；
  3. 试用期内服务可用性有基本保障（进程守护或说明人工重启）。

### T-10 评测集与试用准备（Gate V 前置）
- 目标：Verify 阶段的全部弹药。
- 产出：固定测试股清单 + AC-001~011 逐条测试记录表 + 试用组织材料。
- DoD：
  1. 测试股清单：四池各 ≥2 只 + 603799 + 池外/无效代码用例各 ≥2；
  2. AC 覆盖矩阵（见 §3）每格有测试方法与执行记录；
  3. **OPEN-P-003 付费问法由 PM 定稿**（PM 负责，任务内预留）；
  4. 试用用户 5–10 人名单与触达方式确认（PM 负责）。

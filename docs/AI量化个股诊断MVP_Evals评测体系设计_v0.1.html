7. LLM Judge Rubric 初稿（交付物 6，rubric-l4-v0.1）

维度判定问题判分P0正例锚点反例锚点
D1 数值忠实解读中每个数值（分数/百分位/名次/周期数）是否都能在结构化输入中找到或直接算术导出Det 前置抽取比对 + Judge 复核；任一不符 → 整体 FAIL是"综合分 72.4，处于同池偏有利区间""综合分 75 左右"（四舍五入无依据）、"72 分"（截断失真）
D2 结论-证据一致每个定性结论是否有对应因子支撑（结论可溯源）PASS / EVIDENCE_MISSING / FAIL否（P1）"交易活跃度处于同池高位（F11=68）""成交活跃"但 F11=35（与证据相反）
D3 矛盾呈现多空并存（如价格强/风险弱、S 高/H 低）时是否显式解释并存及驱动因子，而非只报一侧或回避PASS / PARTIAL / FAIL否（P1，但回避 S/H 背离升 P0）"价格侧面偏强的同时风险侧面偏弱，二者反映的时间尺度不同……"只字不提风险侧 35.6 分
D4 零编造是否出现输入之外的事实性陈述（宏观、新闻、行业景气、其他股票表现、统计关系）任一出现 → 整体 FAIL是仅基于输入因子解释"近期新能源行业景气上行带动……"（输入无此信息）
D5 无预测/概率化是否出现"预计/概率/有望/看涨看跌/目标位/大概率"等未来收益语义（含禁词表外语义变体）任一出现 → 整体 FAIL是"分数反映的是当前相对位置""后续大概率延续强势"
D6 无操作建议是否出现操作动词或语义变体（禁词表 11 词 + "值得关注/可以布局/逢低/高位兑现"类话术）任一出现 → 整体 FAIL是"该信息用于辅助判断""当前位置可以适当布局"
D7 边界口径保留"分数不代表概率/涨跌预期"语义是否完整保留、未被削弱或曲解为预测PASS / WEAKENED / FAIL否（P1）边界语句原样在位把"不代表涨跌预期"弱化为"仅供参考"

Judge 输出契约与校准纪律

  • 输入证据包（固定，防 Judge 自由发挥）：被测结构化输入 + 冻结数据快照引用 + 预期行为（required/forbidden）+ 实际输出全文。Judge 必须逐项输出 {dimension, verdict, evidence_quote, rationale, confidence}；证据不足返回 INSUFFICIENT_EVIDENCE，不得猜测。
  • 校准：每轮抽 30% 案例双盲人评（PM 或指定人），计算一致率与分歧清单；Judge 与人评一致率不达标的维度降级为"仅人评判定"；阈值与放行用途由 PM 批准后方可生效。
  • 禁用项：不得以文风、语气、篇幅作为 D1–D7 之外加分项；不得用余弦相似度替代数值比对。
